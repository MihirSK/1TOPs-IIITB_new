2. DEFECTS IN v1 AND FIXES IN v2
 P1 Edge detector: irq_sync and irq_sync_d were both loaded from irq_sources, so
    irq_edge = irq_sync & ~irq_sync_d was always 0 and pending never became 1.
    v2: 2-flop synchroniser + level gateway with claim/complete.
 P2 Address decode: the priority branch (addr[27:22]==0) matched every address
    below 0x400000, so pending (0x1000), enable (0x2000) and threshold/claim
    (0x200000) were unreachable; their own decode constants were also wrong.
    v2: each region decoded correctly.
 P3 Claim selection: the "highest priority" loop kept overwriting, so the LOWEST
    numbered eligible source won and priority was ignored.
    v2: highest priority, ties to the lowest id.
 P4 No bounds checks: out-of-range priority source / enable word / pending word /
    context returned X, and unmapped addresses returned the previous read data.
    v2: they read 0, writes are ignored.
 P5 Source 0 does not exist, but priority[0] and enable bit 0 were writable.
    v2: they read 0.
 P6 A claim read has a side effect; a master that holds req until ack executed it
    twice and silently swallowed a second interrupt.
    v2: accept once (req && !ack), ack one cycle wide.
    [OPEN ITEM: only matters if your bus holds req]

3. DESIGN DECISION (open item O2): level gateway
 v2 treats sources as LEVEL: an asserted source sets pending (also a short pulse);
 claim clears pending and marks the source "in flight" (ignored until completed);
 complete = write of the id to the claim register (ignored if the source is not
 enabled for that context); a source still asserted at complete pends again.
 The contract tests only use short pulses, or levels dropped before the complete,
 so an edge-only gateway also passes them; the level-specific behaviour is O2 and
 is reported as OPEN ITEMS. -define STRICT_OPEN makes them fail.

 Pin-level, no dut.* references. Two configurations run together. Reference model

 synchroniser latency is unspecified): eip per context == model; ack one cycle

 Coverage (a hole fails): every source becomes pending and is claimed, all 8
